push から公開までの流れ

ボタンを押すと、わたしが push したときに裏で起きていることを順に再現します。

  1. git push で GitHub に送る
  2. GitHub Actions が起動する
  3. OIDC で AWS のロールを借りる
  4. aws s3 sync でバケットに反映する
$ ready. ボタンを押してください
